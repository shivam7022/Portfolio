> A modern, editorial dark-themed personal portfolio showcasing full-stack web applications, machine learning systems, and AI engineering projects.

---

## ✨ Features & Highlights

- **Interactive Category Filtering**: Smooth tabbed filtering across Selected Projects (AI & ML, Smart Systems, Full-Stack Web).
- **Ambient Cursor Spotlight & 3D Tilt**: Subtle cursor glow follower and perspective 3D card tilts on desktop.
- **Scroll Progress Indicator**: Dynamic gradient bar tracking scroll position.
- **Tech Stack Marquee**: Continuous seamless ticker highlighting core engineering competencies.
- **Animated Metric Counters**: Auto-animating numbers for projects, certifications, and academic performance.
- **One-Click Email Copy & Toast Feedback**: Direct clipboard action with visual toast notification.
- **Functional Contact Form**: Direct message dispatch via FormSubmit with seamless fallback.
- **Fully Responsive & Accessible**: Built with semantic HTML5, fluid typography, mobile drawer navigation, and reduced-motion considerations.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Modern Glassmorphism, CSS Custom Properties, Flexbox & Grid), Vanilla JavaScript (ES6+)
- **Design System**: Editorial Dark Theme (`#0c0d10`), Cyan accents (`#00b7ff`), Space Grotesk & Inter typography
- **Deployment & CI/CD**: GitHub Actions automated pipeline for GitHub Pages

## 💻 Local Development

Run locally using Python's built-in server or any static file server:

```bash
# Clone the repository
git clone https://github.com/shivam7022/Portfolio.git

# Navigate into the project directory
cd Portfolio

# Start a local HTTP server
python -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your web browser.
